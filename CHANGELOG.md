# Changelog

All notable changes to the Localization3 project will be documented in this file.

## [0.1.0] - 2023-08-10

### Added
- Initial project structure and architecture
- Browser navigation and screenshot capture functionality
- Amazon Nova Pro integration for OCR and language detection
- CSV and HTML report generation
- Manual login support
- Basic CLI interface
- Documentation and examples

### Features
- Support for traversing and capturing screenshots of web pages
- OCR and language detection using Amazon Nova Pro
- Detection of English text in French UI
- Interactive HTML reports with screenshot viewing
- Detailed CSV reports for data analysis

## Roadmap

### Upcoming Features
- Support for additional languages beyond French
- Date/time format validation
- Improved accuracy with fine-tuned Nova Pro model
- Batch processing mode for large sites
- Modal detection and interaction
- Currency and number format validation
